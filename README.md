# Om Patel — Portfolio

Personal portfolio site built with Next.js, [shadcn/ui](https://ui.shadcn.com/), and [Magic UI](https://magicui.design/), deployed on Vercel.

Site content lives in a single config file: [`src/data/resume.tsx`](./src/data/resume.tsx).

Based on the [magicuidesign/portfolio](https://github.com/magicuidesign/portfolio) template.

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
